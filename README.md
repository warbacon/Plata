# 🥈 Plata

<p align="center">
  <strong>Plata</strong> — a lightweight, modern, and open-source PDF viewer
  built with Qt6 and MuPDF.
</p>

<p align="center">
  <em>Actually Good → AG → Silver → Plata (Spanish word)</em>
</p>

![License: AGPLv3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)
![Build](https://img.shields.io/badge/status-early%20development-orange)

> [!IMPORTANT]
> Plata is currently in **very early development** — it doesn’t render PDFs yet!

## ✨ Features

- 🖼️ Modern UI and native performance with [Qt6](https://www.qt.io/)
- 📄 Fast and smooth PDF rendering powered by MuPDF
- 🧠 Focused on simplicity, usability, and responsiveness
